## 三、论文列表(按主题分类)

### A1. 提示注入攻击(Prompt Injection) (26 篇)

- **[Fun-tuning: Characterizing the Vulnerability of Proprietary LLMs to Optimization-Based Prompt Injection Attacks via the Fine-Tuning Interface](https://doi.org/10.1109/SP61157.2025.00121)** — 利用 Gemini 微调接口返回的 loss 类信息做贪心离散优化,为闭源 LLM 生成 prompt injection,成功率 65%–82%。 `S&P 2025` `核心`
- **[Hijacking Large Audio-Language Models via Context-Agnostic and Imperceptible Auditory Prompt Injection](https://doi.org/10.1109/SP63933.2026.00214)** — AudioHijack 用采样梯度估计与混响卷积生成不可感知对抗音频,对 13 个音频 LLM 实现上下文无关的听觉 prompt injection。 `S&P 2026` `相关`
- **[When AI Meets the Web: Prompt Injection Risks in Third-Party AI Chatbot Plugins](https://doi.org/10.1109/SP63933.2026.00062)** — 测量 17 个第三方 chatbot 插件与上万网站,发现 8 个不校验对话历史使直接注入效果提升 3–8 倍,15 个混入不可信内容引入间接注入。 `S&P 2026` `核心`
- **[Context Contamination in LLM Analysis of Network Security Logs: Poison with Passive Prompt Injection and Mitigation Evaluation](https://www.usenix.org/conference/usenixsecurity26/presentation/karanjai)** — 将 prompt injection 载荷植入外部可控日志字段并持久化,待分析师查询时被动触发,并用含 2,569 条对抗样本的 LogInject 基准评测三个生产 LLM 与缓解方案。 `USENIX Security 2026` `相关`
- **[MUZZLE: Adaptive Agentic Red-Teaming of Web Agents Against Indirect Prompt Injection Attacks](https://www.usenix.org/conference/usenixsecurity26/presentation/syros)** — 自动化 agentic red-teaming 框架 MUZZLE,依据 Web agent 执行轨迹定位高显著性注入面并自适应生成上下文相关恶意指令,在 4 个 Web 应用上发现 44 个新攻击。 `USENIX Security 2026` `核心`
- **[Overcoming the Retrieval Barrier: Indirect Prompt Injection in the Wild for LLM Systems](https://www.usenix.org/conference/usenixsecurity26/presentation/chang-hongyan)** — 把间接注入拆成保证被检索命中的 trigger 片段与攻击片段,黑盒下近 100% 被检索,单封投毒邮件即可让 GPT-4o 外泄 SSH 密钥。 `USENIX Security 2026` `核心`
- **[The Attacker Moves Second: Stronger Adaptive Attacks Bypass Defenses Against LLM Jailbreaks and Prompt Injections](https://www.usenix.org/conference/usenixsecurity26/presentation/nasr)** — 论证防御须以自适应攻击者评测,通过调优梯度下降、强化学习、随机搜索与人工引导探索,以超 90% 成功率攻破 12 种越狱与 prompt injection 防御。 `USENIX Security 2026` `相关`
- **[When AIOps Become "AI Oops": Subverting LLM-driven IT Operations via Telemetry Manipulation](https://www.usenix.org/conference/usenixsecurity26/presentation/pasquini)** — 首次分析 AIOps 安全:用错误诱导请求注入伪造 telemetry 使运维 agent 做出破坏基础设施的动作,并以 AIOpsShield 净化遥测数据防御。 `USENIX Security 2026` `核心`
- **[Optimization-based Prompt Injection Attack to LLM-as-a-Judge](https://doi.org/10.1145/3658644.3690291)** — 面向 LLM-as-a-Judge 的优化式提示注入,用梯度方法生成注入序列使目标回答无论候选如何都被选中,并击穿三类已知检测防御。 `CCS 2024` `相关`
- **[PLeak: Prompt Leaking Attacks against Large Language Model Applications](https://doi.org/10.1145/3658644.3670370)** — 闭盒提示泄露攻击,按系统提示前缀逐段增量优化对抗查询,在 Poe 等真实 LLM 应用上高效还原其机密 system prompt。 `CCS 2024` `相关`
- **[ObliInjection: Order-Oblivious Prompt Injection Attack to LLM Agents with Multi-source Data](https://www.ndss-symposium.org/ndss-paper/obliinjection-order-oblivious-prompt-injection-attack-to-llm-agents-with-multi-source-data/)** — 针对多来源输入的 agent 提出 order-oblivious 损失与 orderGCG 优化,使污染片段无论排在何处都能劫持任务,只污染 1 个片段即生效。 `NDSS 2026` `核心`
- **[Prompt-to-SQL Injections in LLM-Integrated Web Applications: Risks and Defenses](https://doi.org/10.1109/ICSE55347.2025.00007)** — 刻画 LangChain/LlamaIndex 网页应用中的 prompt-to-SQL 注入变体,在 7 个 LLM 与 5 个真实应用验证漏洞,并给出四种可集成的防御。 `ICSE 2025` `相关`
- **[Tensor Trust: Interpretable Prompt Injection Attacks from an Online Game](https://openreview.net/forum?id=fsW7wJGLBd)** — 通过在线游戏收集 56 万条人类 prompt injection 攻击与 11.8 万条提示级防御,构建 prompt 提取与劫持两类抗性基准并验证其对真实应用的可迁移性。 `ICLR 2024` `相关`
- **[Eia: Environmental Injection Attack on Generalist Web Agents for Privacy Leakage](https://openreview.net/forum?id=xMOLUzo2Lk)** — 提出环境注入攻击 EIA,在真实网页中植入自适应恶意内容诱使通用 web agent 泄露用户 PII,窃取指定隐私项成功率达 70% 且难以检测。 `ICLR 2025` `核心`
- **[Follow My Instruction and Spill the Beans: Scalable Data Extraction from Retrieval-Augmented Generation Systems](https://openreview.net/forum?id=Y4aWwRh25b)** — 利用指令跟随特性以 prompt injection 逐字提取 RAG 数据库内容,对 25 个定制 GPTs 两次查询内近乎必然泄露,位置偏置消除可显著缓解。 `ICLR 2025` `相关`
- **[ChatInject: Abusing Chat Templates for Prompt Injection in LLM Agents](https://openreview.net/forum?id=WVhgFSKniL)** — 把恶意载荷伪装成模型原生 chat template 并用多轮对话铺垫,在 AgentDojo 上将注入成功率由 5.18% 提到 32.05%,现有 prompt 防御基本失效。 `ICLR 2026` `核心`
- **[RedTeamCUA: Realistic Adversarial Testing of Computer-Use Agents in Hybrid Web-OS Environments](https://openreview.net/forum?id=yWwrgcBoK3)** — 构建 VM 加 Docker 的混合 web-OS 沙箱与 864 例基准,红队测试 computer-use agent 的 indirect prompt injection,端到端成功率最高达五成。 `ICLR 2026` `核心`
- **[VPI-Bench: Visual Prompt Injection Attacks for Computer-Use Agents](https://openreview.net/forum?id=UMauKu2azg)** — 在五个常用平台构造 306 个视觉嵌入恶意提示的交互式测试页,黑盒评测 computer-use 与浏览器 agent,最高受骗率达 100%。 `ICLR 2026` `核心`
- **[UDora: A Unified Red Teaming Framework against LLM Agents by Dynamically Hijacking Their Own Reasoning](https://proceedings.mlr.press/v267/zhang25cl.html)** — 在 agent 推理轨迹中自动定位最优插入点并迭代优化对抗扰动,动态劫持其推理过程,诱导 agent 执行指定恶意动作或调用恶意工具。 `ICML 2025` `核心`
- **[Does AI Reviewer See the Full Picture? Attacking and Defending Multimodal Peer Review](https://openreview.net/forum?id=l8RBjihPFk)** — 针对多模态 AI 审稿提出 PaperGuard,含黑盒 prompt injection 与文本 GCG、图像 PGD 白盒扰动攻击,并用分块嵌入检索定位并消除恶意指令。 `ICML 2026` `相关`
- **[It's a TRAP! Task-Redirecting Agent Persuasion Benchmark for Web Agents](https://openreview.net/forum?id=Smk4fl6Q9E)** — 提出 TRAP 基准,把社会工程说服话术嵌入高保真克隆网页界面实施 prompt injection,使六个前沿模型的 web agent 平均 25% 任务被劫持改道。 `ICML 2026` `核心`
- **[OTora: A Unified Red Teaming Framework for Reasoning-Level Denial-of-Service in LLM Agents](https://openreview.net/forum?id=n6smFKXQWg)** — 提出推理层拒绝服务红队框架 OTora,先优化触发器诱导冗余工具调用,再用遗传搜索放大过度思考,推理 token 增至 10 倍而任务准确率不变。 `ICML 2026` `核心`
- **[Prompt Injection as Role Confusion](https://openreview.net/forum?id=Lm3DQDyIsI)** — 用 role probe 证明 prompt injection 源于角色表征混淆——注入文本占据被模仿可信角色的表示空间,并提出 CoT Forgery 攻击取得 60% 成功率。 `ICML 2026` `核心`
- **[Rapid Poison: Practical Poisoning Attacks Against the Rapid Response Framework](https://openreview.net/forum?id=hvI3Syn2U7)** — 用 prompt injection 把毒样本注入 Rapid Response 越狱分类器的合成训练流水线,1% 投毒率即可制造定向误报与概念级后门绕过。 `ICML 2026` `相关`
- **[Dataset and Lessons Learned from the 2024 SaTML LLM Capture-the-Flag Competition](https://openreview.net/forum?id=WUWHVN4gxk)** — 复盘 SaTML 2024 LLM 夺旗赛的 prompt injection 攻防两阶段,所有防御均至少被攻破一次,并开源 13.7 万条多轮攻击对话数据集。 `NeurIPS 2024` `相关`
- **[TRAP: Targeted Redirecting of Agentic Preferences](https://openreview.net/forum?id=X51kYnijag)** — 用扩散模型在视觉-语言嵌入空间做语义注入,生成视觉自然的对抗图像,无需模型内部访问即可定向操纵 agentic VLM 的选择偏好。 `NeurIPS 2025` `相关`

### A2. 工具与插件攻击(Tool / Plugin Attacks) (8 篇)

- **[Make Agent Defeat Agent: Automatic Detection of Taint-Style Vulnerabilities in LLM-based Agents](https://www.usenix.org/conference/usenixsecurity25/presentation/liu-fengyu)** — AgentFuzz 以 LLM 生成种子并做定向灰盒模糊测试,挖掘 LLM agent 的 taint-style 漏洞,20 个开源 agent 中发现 34 个高危 0-day。 `USENIX Security 2025` `核心`
- **[Autonomy Comes with Costs: Detecting Denial-of-Service Vulnerabilities Caused by Resource Abusing in LLM-based Agents](https://www.usenix.org/conference/usenixsecurity26/presentation/luo)** — 首次系统研究 LLM agent 的资源生命周期缺陷,用定向灰盒 fuzzing 生成耗资源提示,在 20 个开源 agent 中挖出 36 个 DoS 零日漏洞。 `USENIX Security 2026` `核心`
- **[Demystifying RCE Vulnerabilities in LLM-Integrated Apps](https://doi.org/10.1145/3658644.3690338)** — 静态分析 11 个 LLM 应用框架的代码执行调用链并用提示注入触发利用,发现 20 个 RCE 类漏洞、11 个 CVE,成功攻陷 17 个真实应用。 `CCS 2024` `核心`
- **[Les Dissonances: Cross-Tool Harvesting and Polluting in Pool-of-Tools Empowered LLM Agents](https://www.ndss-symposium.org/ndss-paper/les-dissonances-cross-tool-harvesting-and-polluting-in-pool-of-tools-empowered-llm-agents/)** — 系统分析多工具 agent 的任务控制流,提出跨工具窃取与污染攻击 XTHP,并用动态扫描工具 Chord 发现 66 个真实工具中 75% 可被利用。 `NDSS 2026` `核心`
- **[Prompt Injection Attack to Tool Selection in LLM Agents](https://www.ndss-symposium.org/ndss-paper/prompt-injection-attack-to-tool-selection-in-llm-agents/)** — 以两阶段优化生成恶意工具文档并投放到工具库,在 no-box 场景劫持 agent 的工具检索与选择,并证明 StruQ、SecAlign 等防御失效。 `NDSS 2026` `核心`
- **[Adversarial Search Engine Optimization for Large Language Models](https://openreview.net/forum?id=hkdqxN3c7t)** — 提出 Preference Manipulation Attack,用精心构造的网页内容与插件文档操纵 LLM 的第三方内容选择以抬高攻击者产品,在 Bing、Perplexity 与 GPT-4 插件上生效。 `ICLR 2025` `相关`
- **[Sponge Tool Attack: Stealthy Denial-of-Efficiency against Tool-Augmented Agentic Reasoning](https://openreview.net/forum?id=g9fZTb53kL)** — 在仅能改写输入 prompt 的条件下,用多 agent 协作生成语义保真的改写,使 tool-augmented agent 的推理轨迹冗长绕远,制造隐蔽的算力耗尽攻击。 `ICML 2026` `核心`
- **[Attractive Metadata Attack: Inducing LLM Agents to Invoke Malicious Tools](http://papers.nips.cc/paper_files/paper/2025/hash/ee46288ab2aaf5c6e53aebebe719712c-Abstract-Conference.html)** — 提出 Attractive Metadata Attack,黑盒迭代优化生成诱人工具元数据诱导 agent 优先选择恶意工具,成功率 81%-95% 且可绕过 MCP 选择协议。 `NeurIPS 2025` `核心`

### A3. 记忆与知识投毒(Memory / RAG Poisoning) (28 篇)

- **[Adversarial Hubness in Multi-Modal Retrieval](https://doi.org/10.1109/SP63933.2026.00158)** — 构造 adversarial hub,使单张图片被 25000 条查询中的 2.1 万条检索为 top-1,实现多模态 RAG 向量库的通用检索投毒,现有 hubness 缓解手段失效。 `S&P 2026` `相关`
- **[GraphRAG under Fire](https://sp2026.ieee-security.org/accepted-papers.html)** — GragPoison 利用知识图谱共享关系构造投毒文本,通过关系注入、关系增强与叙事伪装同时攻陷 GraphRAG 的多个查询,成功率达 98%。 `S&P 2026` `相关`
- **[Fact-Saboteurs: A Taxonomy of Evidence Manipulation Attacks against Fact-Verification Systems](https://www.usenix.org/conference/usenixsecurity23/presentation/abdelnabi)** — 提出针对检索式事实核查系统的证据操纵攻击分类,通过伪装关键证据或投放贴合声明的误导证据大幅拉低核查准确率。 `USENIX Security 2023` `相关`
- **[Machine Against the RAG: Jamming Retrieval-Augmented Generation with Blocker Documents](https://www.usenix.org/conference/usenixsecurity25/presentation/shafran)** — 向 RAG 知识库注入单篇 blocker 文档即可让系统拒答特定查询,用黑盒优化生成且无需知晓嵌入模型与后端 LLM。 `USENIX Security 2025` `相关`
- **[PoisonedRAG: Knowledge Corruption Attacks to Retrieval-Augmented Generation of Large Language Models](https://www.usenix.org/conference/usenixsecurity25/presentation/zou-poisonedrag)** — 首次提出 RAG 知识库投毒攻击,把恶意文本构造转为优化问题,每个目标问题仅注入 5 条文本即可让 LLM 输出攻击者指定答案,成功率约 90%。 `USENIX Security 2025` `相关`
- **[Topic-FlipRAG: Topic-Orientated Adversarial Opinion Manipulation Attacks to Retrieval-Augmented Generation Models](https://www.usenix.org/conference/usenixsecurity25/presentation/gong-yuyang)** — 两阶段主题级 RAG 投毒攻击,结合对抗排序与语义级扰动,使模型在整类相关查询上系统性翻转立场,现有缓解手段难以拦截。 `USENIX Security 2025` `相关`
- **[BadGraph: Structural Knowledge Isolation Attacks against Graph Retrieval-Augmented Generation](https://www.usenix.org/conference/usenixsecurity26/presentation/yan-leiming)** — 面向 Graph Retrieval-Augmented Generation 的结构性知识隔离攻击 BadGraph,通过操纵知识图谱结构使目标知识在检索阶段被隔离,进而扭曲生成结果。 `USENIX Security 2026` `相关`
- **[Confundo: Learning to Generate Robust Poison for Practical RAG Systems](https://www.usenix.org/conference/usenixsecurity26/presentation/hu-haoyang)** — learning-to-poison 框架 Confundo 微调 LLM 作为投毒生成器,抵抗内容分块与查询漂移,可篡改事实、诱导偏见并触发幻觉,亦可反向保护网页内容。 `USENIX Security 2026` `相关`
- **[FragFuse: Bypassing Access Control of Large Language Model Agents via Memory-Based Query Fragmentation and Fusion](https://www.usenix.org/conference/usenixsecurity26/presentation/rao)** — 将违规内容拆分为良性片段写入 agent 长期记忆,再经检索融合重建攻击查询以绕过访问控制,三种机制下平均绕过率 86.3%。 `USENIX Security 2026` `核心`
- **[FlippedRAG: Black-Box Opinion Manipulation Adversarial Attacks to Retrieval-Augmented Generation Models](https://doi.org/10.1145/3719027.3765023)** — 通过枚举查询逆向出代理检索器,再据其构造毒化触发文档,黑盒下让 RAG 在争议话题上平均立场翻转 50%,并改变 20% 用户认知。 `CCS 2025` `相关`

## 统计方法

为保证**完整性**和**链接真实性**,采用多源交叉检索 + 逐条机器验证:

1. **权威目录全量筛查**:安全四大和软工会议以 DBLP XML、官方 accepted list 及技术日程为底表,先遍历全部标题,再按摘要和正文复核边界项。
2. **AI 顶会摘要级筛查**:ICLR、ICML、NeurIPS 使用 OpenReview / PMLR / NeurIPS proceedings 的录用记录与摘要,组合 Agent、MCP、工具、RAG、安全、隐私、攻击、防御等词族检索并人工复扫。
3. **2026 年滚动补查**:ICLR、ICML、ICSE、FSE、S&P、NDSS 采用官方录用页;USENIX Security 2026 采用已经上线的完整 technical sessions,覆盖早期 Cycle 1 与后续公开论文。
4. **社区清单交叉核对**:Awesome-Agentic-Security、Awesome-MCP-Security 等社区列表仅用于发现候选,会议归属仍以 DBLP、OpenReview、PMLR 或会议官网为准。
5. **链接强验证**:每条链接不仅检查可访问性,更验证「链接确实指向这篇论文」——
   - DOI 链接:调用 Crossref API 比对论文标题与会议名称;
   - OpenReview 链接:用本地 OpenReview 全量镜像核对 forum ID ↔ 标题 ↔ 会议 ↔ 年份;
   - 官网链接:抓取页面正文比对标题。

6. **对抗式范围审计**:全部候选再由审计 agent 逐条复判「是否具备实质 agent 要素」——工具调用 / function calling / MCP 协议、与外部环境交互(网页 / GUI / OS / 代码库 / 物理世界)、多步自主执行与规划、多智能体交互、检索或记忆读写、具身动作输出、LLM 集成部署系统,**至少命中一项且同时具备安全要素**才保留;判为超范围的再交第二批 agent 专门尝试反驳,反驳成立则恢复。本轮共移出 71 篇(见附录 A),另有 6 篇经反驳恢复。

**收录口径**:分 `核心` 与 `相关` 两档。核心 = 直接针对 LLM Agent / MCP 的攻防、评测、生态测量;相关 = 沾边工作(LLM 集成应用注入、RAG 投毒、function calling 鲁棒性、agentic 场景越狱、AI control、agent 欺骗等)。判定从宽,不确定者收录并标为 `相关`。

**边界说明**:这不是全部 LLM 安全论文的汇总。仅当工作能连接到 Agent/MCP 的攻击面、运行时、工具/记忆/RAG、自治行为或相邻评测时才收录;纯模型压缩、通用水印、普通对抗样本等无明确桥接的工作仍排除。主会的 Poster、Demo、Datasets & Benchmarks 与 Position 分轨保留并标为 `相关`,Workshop 不计入。
